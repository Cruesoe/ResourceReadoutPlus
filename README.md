# Resource Readout+

Replaces the resource list at the top left of the map with a panel in the look of the UI Rethemed mods.

- Resources sorted into foldable, nested groups with totals: essentials, food (meat and fish, vegetables, animal products, animal feed), meals, medicine, drugs (social, hard, medical, serums and catalysts), textiles, materials, manufactured goods, ammo (mortar shells and any mod ammo), items and waste. Make your own groups and subgroups, rename, reorder and nest any of them.
- An organizer window for groups and resources: drag resources into order, hide or show them one by one, search every resource and move it to any group.
- Look-alike items such as leathers, wools, stone blocks, fish and eggs combined into one row that opens to show each kind.
- The base game's simple list and category tree as alternative modes, in the same look.
- A cog on the panel for switching the list and opening the settings, a background opacity slider, and options to unfold the panel only while the mouse is over it or hide its title bar so only the resources show.
- Item names, row tooltips with storage, map-wide counts, value and recent change.
- Click a row to jump to where it is stored; drag rows to reorder or regroup them.
- Pin rows to the top, set minimum stock levels with a low-stock alert, view a resource's history, count everything on the map, hide rows and search the list.
- Small arrows showing what has gone up or down over the last day, a chart of the last few days in each row's tooltip and an estimate of when falling resources run out.
- A filter that shows only trending, falling, low-stock or new resources, switched from the title bar or a hotkey, and an option to sort rows by how much they changed.
- Marks on resources stored for the first time, or back in stock after running out, that clear themselves after a while or when clicked.
